# Requirements

- Multi-track piano-roll editing with selection, dragging, resizing, keyboard operations, undo/redo and exact tick/velocity fields.
- Explicit transport, seamless bar-range loop, metronome, track mix and lazy same-origin recorded orchestra/piano. Stop audio on page hiding and exit. Preserve existing sound engines and project format.
- User-approved 16-track expansion: 15 melodic plus one percussion kit; true instrument identity and GM programs, searchable family library and audition. Distinguish sampled instruments from synth presets and spell out compact-library limits.
- Draw/select/erase, marquee, velocity lane, chord quality/inversion, musical-duration presets and original orchestral/chamber/quartet/electronic arrangements. Prioritize usable defaults and mobile-visible mix controls.
- Original editable sample composition; new/open/save JSON; bounded browser autosave.
- Download real 48 kHz stereo 24-bit PCM WAV, Standard MIDI type 1, MusicXML, vector score SVG and 300 dpi A4 score PDF.
- Clear distinction between exact performance timing and the sixteenth-note printed score. No fabricated waveforms, sound controls or download buttons.
- Responsive product UI, keyboard focus, no whole-page horizontal overflow.
- Pure model/export tests and real browser interaction/download validation before publishing.
- Local MIDI 0/1 import with source-track/channel selection, explicit 15 melodic + 1 kit budget, exact tempo/meter changes through playback and re-export, and no silent loss of notes. Preserve legacy JSON and browser records. Disclose unsupported MIDI controls and sound substitutions before confirmation. Version-2 imports may use 512 bars; WAV and note/resource bounds remain enforced.
- Rename the repository/Pages path to music-room, update WEB LAB including a real preview, and verify new URL, remote CI and existing local-save continuity independently.
