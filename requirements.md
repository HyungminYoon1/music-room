# Requirements

- Multi-track piano-roll editing with selection, dragging, resizing, keyboard operations, undo/redo and exact tick/velocity fields.
- Explicit transport, loop, track mix, instruments and real sampled piano. Stop audio on page hiding and exit.
- Original editable sample composition; new/open/save JSON; bounded browser autosave.
- Download real 48 kHz stereo 24-bit PCM WAV, Standard MIDI type 1, MusicXML, vector score SVG and 300 dpi A4 score PDF.
- Clear distinction between exact performance timing and the sixteenth-note printed score. No fabricated waveforms, sound controls or download buttons.
- Responsive product UI, keyboard focus, no whole-page horizontal overflow.
- Pure model/export tests and real browser interaction/download validation before publishing.
