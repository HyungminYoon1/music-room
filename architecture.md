# MUSIC ROOM architecture (repository: score-lab)

Static GitHub Pages application. No backend, accounts, microphone, uploads or CDN. Editable composition data and rendering remain in the browser. Same-origin piano and CC0 orchestra samples are fetched only following an explicit audio action, for the notes actually used. WEB LAB's shared storage is never read or written.

Layers: `model.js` owns validated musical data, history and MIDI/MusicXML encoding; `instruments.js` owns instrument identity, GM mapping and ranges; `sampler.js` owns bounded same-origin asset loading; `editing.js` and `templates.js` own pure composition operations; `audio.js` owns native Web Audio voices, scheduling and WAV rendering; `notation.js` owns VexFlow engraving and PDF; `app.js` owns DOM interaction. Libraries are pinned and bundled into same-origin vendor modules. Build tooling is not required by visitors.

Performance data uses 960 ticks per quarter note. Printed notation explicitly quantizes to a sixteenth-note grid. Quantization never modifies the composition, MIDI or audio. MusicXML retains original tick durations, with separate voices for overlapping notes. Piano sample fidelity is that of the redistributed MP3 files, not the original multi-velocity raw bank.

Limits: 16 tracks (up to 15 melodic tracks and one percussion-kit track; MIDI channel 10 is reserved), 4096 notes, 64 bars, 40–240 BPM, sounding MIDI pitches 21–108, 4/4, 3/4 or 6/8. Pitched percussion, including timpani, uses a melodic channel. Sample cache is bounded to 128 MiB decoded PCM and four concurrent downloads. Real-time voices are bounded to 96; older voices may be released at that boundary, while offline rendering includes all notes. Offline WAV exports are limited to 180 seconds including release tails. No silent truncation of exported composition. One bounded composition is saved under `score-lab-project-v1`; malformed existing data is preserved until explicit replacement. Existing six instrument IDs retain their sound engines and the version-1 file format remains readable.

VSCO Community Edition samples are redistributed under CC0 with pinned source/mapping revisions and per-file hashes. The compact bank uses one dynamic layer, mono PCM16 at the original 44.1/48 kHz rate, bounded durations and crossfaded sustain loops. Velocity controls amplitude, not true multi-layer timbre. This is a browser composer, not a VST host or a full orchestral sample library. Audio downloads have no third-party origin. Session-only selection, edit tool and loop settings do not add storage keys.

See docs/decisions.md. Changes to these boundaries require a documented decision.
